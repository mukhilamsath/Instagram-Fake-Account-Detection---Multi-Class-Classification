About FakeGuard AI

Technical details, dataset info, and project architecture

🎯

Project Goal

A multi-class machine learning system to classify Instagram accounts into four categories — real users, active fakes, inactive fakes, and spammers — helping platforms and researchers identify inauthentic behaviour at scale.

🗂️

Dataset

Trained on 43,307 Instagram accounts with features including post count, follower/following ratio, bio length, profile picture, external link, engagement metrics, and derived engineered features.

43,307 samples Balanced classes 17+ features
🧠

Machine Learning

Ensemble approach combining Random Forest (500 trees, balanced subsample weighting) and XGBoost (500 estimators, logloss optimised) with extensive feature engineering including log transforms, ratio features, and binary flags.

Random Forest XGBoost Scikit-learn
⚡

Tech Stack

  • Python 3.11+
  • FastAPI + Uvicorn
  • Scikit-learn + XGBoost
  • Pandas + NumPy
  • Vanilla JS + CSS (SPA)
🔬

Feature Engineering

  • 📐 Follower/Following ratio
  • 📐 Followers per post
  • 📐 Engagement rate (simulated)
  • 📐 Log-transforms for skewed cols
  • 📐 Binary flags: has_bio, has_pic
  • 📐 Irregular post detection
🏷️

Class Labels

✅ r — Real Account
⚠️ a — Active Fake
👻 i — Inactive Fake
🤖 s — Spammer Fake
